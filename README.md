# Purvanchal Ganeshotsav Mandal - Receipt Generator (Node.js Edition)

A modernized, mobile-friendly Node.js web application for generating society donation/contribution receipts with server-side PDF & PNG receipt generation and Google Sheets/Drive integration.

## Features
- **Backend PDF/PNG Generation**: Server-side receipt rendering via Puppeteer eliminates client-side canvas distortions and font issues.
- **Multi-Language Support**: Marathi (`mr`), Hindi (`hi`), and English (`en`) with automatic Number-to-Words conversion.
- **Mobile-First UX**: Responsive layout, touch-friendly min 48px controls, instant dashboard stats counters.
- **Google Sheets & Drive Integration**: Direct integration with Google Apps Script backend.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the application:
   ```bash
   npm start
   ```

3. Open your browser at `http://localhost:3000`.
